# NumPy, Pandas & Statistics Learning Hub

A hands-on collection of Jupyter notebooks and practice material for learning **NumPy**, **Pandas**, and foundational **statistics for machine learning**. The materials range from introductory concepts and guided lessons to assignments, scenario-based exercises, and question banks.

## Getting started

### Requirements

- Python 3.9 or later
- JupyterLab or Jupyter Notebook
- NumPy and Pandas

Install the tools with pip:

```bash
python -m pip install numpy pandas jupyterlab
```

### Run the notebooks

Clone the repository, enter its directory, and launch JupyterLab:

```bash
git clone <repository-url>
cd <repository-directory>
jupyter lab
```

Open a notebook from the `NumPy`, `Pandas`, or `Statistics` folder and run its cells in order. Some notebooks may require additional packages depending on their examples; install those packages if a notebook reports a missing import.

## Suggested learning path

1. Start with the NumPy foundations notebook and its practice assignment.
2. Continue with the NumPy AI/ML training notebook, then solve the question bank and scenarios.
3. Study the Pandas DataFrame guide before attempting the Pandas question bank.
4. Use the integration exercises to practice working with NumPy arrays and Pandas objects together.
5. Work through the statistics workbook alongside or after the library exercises.
